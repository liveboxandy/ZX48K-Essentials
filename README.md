# ZX48essentials
Modernized version of Sinclair ZX 48K computer

Sinclair ZX Spectrum 48K computer released in 1982 was not the best one in terms of features but for sure became one of the most influentials one. A lot of hobbiest who collect, repair, mods Spectrum think about creating their own version. Keeping the original idea/design but replacing those elments that you could do better. 

For sure we leave those two things that make a Z80 system the Spectrum - ULA with its architecture and ROM and for sure we need to improve on memory. While changing the memory we will also change power supply design. 

Changes.
We leave the chip but we don't want to bother with the analogue circuit that produces TV signal. Yhe idea is to use modern replacement produces by vRetro Design what also has RGB output. Thus we don't need to bother with all that analogue circuity that occupies one third of the board and produces TV signal. We add mini DIN8 connector (as in Harlequin) to output signal.
Dynamically refreshed Lower RAM can be replaced with more up to date static RAM that also allows to get rid of most of power supply section because we no longer need to have -5V amd +12V supply for 4116 chips.
